HIDDEN NETWORK SERVICE CENTER — মোবাইল সেটআপ

এই ZIP-এ আছে: index.html, manifest.json, sw.js এবং icons ফোল্ডার।
গুরুত্বপূর্ণ:
1) WhatsApp-এর জন্য index.html-এর ADMIN_PHONE মানটি ঠিক করুন। এখন এটি 8801765254239 (প্রদত্ত যোগাযোগ নম্বর 01765254239-কে WhatsApp ফরম্যাটে ধরা হয়েছে; WhatsApp চালু আছে কি না যাচাই করুন)।
2) বিকাশ/নগদের আসল পেমেন্ট নম্বর যোগ করার আগে নম্বর নিশ্চিত করুন।
3) এটি একটি front-end demo। অর্ডার ডেটাবেসে জমা হয় না; WhatsApp-এ বার্তা তৈরি করে। ব্রাউজারে শুধু লোকালভাবে কিছু সংরক্ষণ করা হয় না।
4) অনলাইনে প্রকাশ করতে HTTPS hosting দরকার; তখনই PWA install করা যাবে।
5) বিনামূল্যে GitHub Pages ব্যবহার করতে পারেন: GitHub-এ repository বানিয়ে ফাইলগুলো upload করুন, Settings > Pages থেকে deploy করুন।
6) সাইট প্রকাশের পর Android Chrome-এ সাইট খুলুন > ⋮ মেনু > Install app / Add to Home screen।
7) APK বানাতে প্রকাশিত HTTPS URL PWABuilder (https://www.pwabuilder.com/) এ দিন। প্যাকেজিংয়ের জন্য অতিরিক্ত যাচাই/সেটআপ লাগতে পারে।
8) সত্যিকারের অর্ডার/পেমেন্ট রেকর্ড, Admin dashboard, SMS বা automatic recharge চাইলে backend/database এবং নিরাপদ access control দরকার।
